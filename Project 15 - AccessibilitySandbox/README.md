# Project 15 - AccessibilitySandbox

AccessibilitySandbox explores SwiftUI accessibility tools. It practices labels, values, hints, image descriptions, grouping, and making existing views easier to use with assistive technologies.

## Contents

- `AccessibilitySandbox.xcodeproj`: Xcode project file.
- `AccessibilitySandbox/`: SwiftUI app source.
- `FixedProjects/`: Updated versions of earlier projects.
- `Resources/`: Image assets used by the accessibility examples.
