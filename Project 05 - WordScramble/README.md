# Project 05 - WordScramble

WordScramble is a word game built with SwiftUI. It practices list rendering, text entry, string validation, and loading a starter word list from bundled resources.

## Contents

- `WordScramble.xcodeproj`: Xcode project file.
- `WordScramble/`: SwiftUI app source.
- `Resources/start.txt`: Word list used by the game.
